Sacred installation ritual

Install in
4 steps.
(We counted.)

1
Download the extension
Click the button below and save the .zip file somewhere you will remember. Your Downloads folder. Your Desktop. A folder called "definitely not a virus". Whatever works.

Download the-otf-archives-v0.4.0.zip
It's small. Smaller than a photo of your lunch. You'll be fine.
2
Unzip it
Find the downloaded file and unzip it. On Mac: double-click. On Windows: right-click → Extract All. You should see a folder called src inside. That folder is the extension. Do not rename it. Do not move its contents around. It knows. If you can't find where it downloaded, check your Downloads folder. It's always the Downloads folder.
3
Open Chrome Extensions
In Chrome, go to chrome://extensions in the address bar. You will see a toggle in the top right that says Developer mode. Turn it on. Chrome will look slightly different. This is normal. You are not in trouble. Chrome may warn you that developer mode is on every time you open it. This is Chrome being dramatic. You can dismiss it.
4
Load the extension
Click Load unpacked in the top left. A file picker will appear. Navigate to where you unzipped the file and select the src folder inside it. Click Select (or Open on Windows).

The OTF Archives will appear in your extensions list. You'll see the icon in your Chrome toolbar. You're done. Go read the OTF. The lore awaits. If the icon doesn't appear in the toolbar, click the puzzle piece 🧩 icon next to the address bar and pin it. Obviously.

How to use it.
(You already know.)

Some topics hide treasure. Each topic can reward you once per week. Older topics hide rarer treasure. Click the extension icon in your toolbar to see your collection. That's the whole game. There is no leaderboard. There is no winning. There is only the OTF.
